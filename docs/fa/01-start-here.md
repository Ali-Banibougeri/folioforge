# ۰۱ — شروع برای کسانی که برنامه‌نویسی بلد نیستند

[← راهنمای اصلی FolioForge](../../README.fa.md) · [English](../en/01-start-here.md)

این راهنما توضیح می‌دهد چطور از فایل رزومه به یک وب‌سایت عمومی برسید. لازم نیست پیش از شروع تمام خطوط کد را بفهمید.

## مسیر خود را انتخاب کنید

**روش A — محیط کدنویسی هوش مصنوعی (پیشنهادی):** مخزن را Clone یا دانلود کنید، پوشه آن را در محیطی باز کنید که عامل هوش مصنوعی اجازه ویرایش فایل‌های محلی دارد، رزومه را پیوست کنید و دستور کوتاه README.md را بدهید. عامل باید تغییرها را اعمال کند و تست‌ها را اجرا کند.

**روش B — ChatGPT بدون اتصال مستقیم به کد:** مخزن را به صورت ZIP دانلود کنید. ZIP و رزومه را در گفت‌وگویی که امکان کار با فایل دارد بارگذاری کنید و متن prompts/portfolio-fa.md را بدهید. خروجی کامل ZIP را بخواهید، نه فقط چند قطعه کد. برای انتشار همچنان باید خروجی را در GitHub قرار دهید.

**روش C — ویرایش دستی:** فایل starter/site/assets/portfolio-data.js را با ویرایشگر متن تغییر دهید. این روش برای کسانی است که با ویرایش داده‌های JavaScript آشنا هستند.

## گام ۱: رزومه را آماده کنید

رزومه‌ای را به ابزار هوش مصنوعی بدهید که با ارسال آن مشکلی ندارید. اطلاعاتی که نباید عمومی شوند را حذف کنید؛ مانند آدرس خانه، شماره‌های شناسایی، تلفن خصوصی یا اطلاعات تماس معرف‌ها.

رزومه باید تنها شامل واقعیت‌هایی باشد که مایل هستید منتشر شوند. اگر درباره اطلاعاتی مطمئن نیستید، سایت باید آن را حذف کند یا به صورت جای‌خالی مشخص نشان دهد.

## گام ۲: یک پیام روشن انتخاب کنید

این جمله را کامل کنید:

    من به [مخاطب] کمک می‌کنم به [نتیجه واقعی] برسد، با استفاده از [توانایی‌های تأییدشده].

برای نمونه، یک مهندس نرم‌افزار ممکن است بر ساخت سیستم‌های قابل اتکا تمرکز کند؛ یک پژوهشگر ممکن است پژوهش‌ها، روش‌ها و حوزه علمی خود را برجسته کند. جمله باید دقیق و واقعی باشد.

## گام ۳: قالب آماده را بشناسید

سایت عمداً ایستا ساخته شده است. HTML ساختار محتوا را تعریف می‌کند، CSS ظاهر آن را می‌سازد و JavaScript اطلاعات رزومه را روی صفحه نمایش می‌دهد. صفحه اصلی برای میزبانی نیازی به بک‌اند ندارد.

فایل اصلی محتوا starter/site/assets/portfolio-data.js است. نسخه انگلیسی و فارسی رزومه در آن قرار دارد. عامل هوش مصنوعی باید مقدارهای نمونه را بر اساس رزومه شما جایگزین کند؛ نه اینکه تمام رزومه را در یک پاراگراف بریزد.

آرکید یک بخش مستقل و اختیاری است. هر رزومه حرفه‌ای به بازی نیاز ندارد؛ اگر با مخاطب شغلی سازگار نیست، مقدار features.arcadeEnabled را false کنید.

## گام ۴: سایت را محلی ببینید

اگر می‌خواهید تست‌های محلی را اجرا کنید، یک نسخه جدید از Node.js LTS نصب کنید. برای پیش‌نمایش سایت، در پوشه اصلی مخزن ترمینال باز کنید و دستور زیر را اجرا کنید:

    python -m http.server 8000

سپس به http://localhost:8000/starter/site/ بروید. گردش‌کار انتشار، محتویات starter/site را به عنوان ریشه سایت منتشر می‌کند؛ در آن حالت مسیرهای نسبی درست کار می‌کنند.

برای توقف سرور Ctrl+C را بزنید. اگر Python ندارید، افزونه سرور محلی ویرایشگر شما هم می‌تواند استفاده شود.

## گام ۵: نتیجه را بررسی کنید

- تمام بخش‌ها را در دو زبان بخوانید.
- لینک پروژه‌ها و راه‌های تماس را باز کنید.
- متن نمونه و لینک‌های جای‌گزین را حذف کنید.
- چیدمان موبایل و دسکتاپ را بررسی کنید.
- با Print → Save as PDF خروجی بگیرید و آن را ببینید.
- اگر آرکید را فعال کرده‌اید، یک دور از هر بازی را کامل بازی کنید.
- دستور node scripts/check.mjs را اجرا کنید.

## گام ۶: انتشار

گردش‌کار GitHub Actions محتویات starter/site را منتشر می‌کند. یک بار در هر مخزن، به Settings → Pages بروید و منبع را روی GitHub Actions قرار دهید. پس از آن، انتشار با push به شاخه main انجام می‌شود.

عامل هوش مصنوعی می‌تواند فایل‌ها را بسازد و تست کند؛ اما انتشار به مجوزهای مخزن و تنظیمات حساب GitHub هم وابسته است.

## چند اصطلاح ساده

- **Repository یا مخزن:** پوشه پروژه روی GitHub به همراه تاریخچه تغییرها.
- **Clone:** ساخت یک نسخه محلی که به مخزن GitHub متصل می‌ماند.
- **Commit:** یک نقطه ثبت‌شده از تغییرها.
- **Deploy یا انتشار:** قرار دادن خروجی سایت روی میزبان تا دیگران بتوانند آن را باز کنند.
- **Responsive یا واکنش‌گرا:** سازگاری چیدمان با موبایل، تبلت و دسکتاپ.
- **RTL/LTR:** جهت نوشتار راست‌به‌چپ برای فارسی و چپ‌به‌راست برای انگلیسی.

## اشتباهات رایج

- انتشار قالب بدون جایگزین کردن متن نمونه.
- ساختن عدد یا دستاورد غیرواقعی برای قوی‌تر نشان دادن رزومه.
- باقی گذاشتن لینک ساختگی برای شرکت یا پروژه.
- قرار دادن API secret در کد مرورگر.
- تصور اینکه موفقیت بررسی نحوی یعنی سایت بی‌نقص است.

هدف ساخت طولانی‌ترین رزومه نیست؛ هدف ایجاد اولین تصویر حرفه‌ای، مفید، واقعی و خواناست.

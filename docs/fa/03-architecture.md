# ۰۳ — معماری وب‌سایت را بشناس

[← راهنمای اصلی](../../README.fa.md) · [English](../en/03-architecture.md)

FolioForge صفحه رزومه را ایستا نگه می‌دارد. بنابراین سریع بارگذاری می‌شود، میزبانی کم‌هزینه‌ای دارد و عامل کدنویسی می‌تواند به‌راحتی آن را شخصی‌سازی کند. تنها قابلیت اختیاری سمت سرور، شمارنده بازدید مشترک است.

## بخش مرورگر

- HTML بخش‌های معنایی و کنترل‌های قابل‌دسترس را تعریف می‌کند.
- CSS در starter/site/assets/styles.css سیستم طراحی، واکنش‌گرایی، چاپ و تنظیم RTL را مشخص می‌کند.
- starter/site/assets/portfolio-data.js اطلاعات رزومه به فارسی و انگلیسی و رنگ‌های تم را نگه می‌دارد.
- starter/site/assets/site.js بخش‌های تجربه، پروژه، مهارت، تحصیلات و تماس را با گره‌های متنی DOM می‌سازد؛ متن رزومه به‌عنوان HTML اجرایی تفسیر نمی‌شود.
- starter/site/assets/site-config.js تنظیمات عمومی مرورگر و جای‌خالی کلید publishable را دارد.
- starter/site/assets/site-api.js درخواست عمومی شمارنده بازدید را می‌فرستد و کلید secret یا service-role در آن وجود ندارد.

## چرا محتوا از ساختار جداست؟

عامل هوش مصنوعی باید بتواند تجربه و پروژه‌ها را ویرایش کند بدون اینکه ساختار صفحه را از نو بنویسد. این کار نگهداری سایت را ساده می‌کند و نشان می‌دهد اطلاعات واقعی در کجا قرار می‌گیرند.

عنوان، تاریخ، نام و لینک تأییدشده وارد کنید. اگر مقداری مشخص نیست، آن را حذف کنید یا جای‌خالی روشن بگذارید.

## تغییر زبان

داده رزومه دو بخش فارسی و انگلیسی دارد. اسکریپت نمایش، زبان و جهت سند را عوض می‌کند و محتوای همان زبان را نشان می‌دهد. انگلیسی چپ‌به‌راست و فارسی راست‌به‌چپ است. URL، ایمیل، نام پروژه و فناوری را در متن ترکیبی خوانا نگه دارید.

## بک‌اند اختیاری شمارنده بازدید

صفحه رزومه به بک‌اند نیاز ندارد. شمارنده بازدید از یک جدول Supabase و یک تابع Edge استفاده می‌کند:

۱. مرورگر شناسه‌ای تصادفی برای خود ایجاد یا از localStorage بازیابی می‌کند.
۲. مرورگر رویداد بازدید و کلید عمومی publishable را به تابع شمارنده می‌فرستد.
۳. تابع مبدأ، کلید، ساختار درخواست و محدودیت نرخ را بررسی می‌کند.
۴. تابع شناسه مرورگر و IP را با هش سمت سرور تبدیل می‌کند.
۵. دیتابیس حداکثر یک بازدید برای هر شناسه مرورگر در هر روز UTC نگه می‌دارد.
۶. تابع تعداد تقریبی را برمی‌گرداند.

RLS فعال است و نوشتن مستقیم نقش ناشناس مسدود شده است. نوشتن دارای مجوز فقط سمت سرور انجام می‌شود. اگر پروژه تنظیم نشده باشد، شمارنده کار نمی‌کند ولی صفحه رزومه همچنان قابل استفاده است.

## انتشار استاتیک

گردش‌کار GitHub Actions فقط محتویات starter/site را منتشر می‌کند. مستندات راه‌اندازی و سورس تابع سرور داخل مخزن می‌مانند و به خروجی وب‌سایت کپی نمی‌شوند.

GitHub Pages کد سرور را اجرا نمی‌کند؛ تابع اختیاری شمارنده در Supabase Edge Function اجرا می‌شود.

## تغییر امن پروژه

۱. فایل مرتبط و رفتار فعلی را بخوان.
۲. کوچک‌ترین تغییر درست را اعمال کن.
۳. متن فارسی و انگلیسی را هماهنگ نگه دار.
۴. node scripts/check.mjs را اجرا کن.
۵. موبایل، دسکتاپ، تغییر زبان، لینک‌ها و چاپ را آزمایش کن.
۶. اگر شمارنده تغییر کرده، پس از راه‌اندازی پاسخ API را بررسی کن.
۷. پیش از commit فایل‌های جدید را از نظر اطلاعات شخصی و کلید محرمانه بررسی کن.

# ۰۳ — معماری وب‌سایت را بشناس

[← راهنمای اصلی](../../README.fa.md) · [English](../en/03-architecture.md)

FolioForge صفحه رزومه را ایستا نگه می‌دارد؛ بنابراین سریع، کم‌هزینه و برای شخصی‌سازی توسط عامل کدنویسی ساده است. تنها قابلیت اختیاری سمت سرور، شمارنده بازدید مشترک است.

## بخش مرورگر

- HTML بخش‌های معنایی و کنترل‌های قابل‌دسترس را تعریف می‌کند.
- CSS در starter/site/assets/styles.css طراحی، واکنش‌گرایی، چاپ و تنظیم RTL را مشخص می‌کند.
- starter/site/assets/portfolio-data.js محتوای رزومه به فارسی و انگلیسی و رنگ‌های تم را نگه می‌دارد.
- starter/site/assets/site.js بخش‌های رزومه را با گره‌های متنی DOM می‌سازد تا متن رزومه به‌عنوان HTML اجرایی تفسیر نشود.
- starter/site/assets/site-config.js تنظیمات عمومی مرورگر و جای‌خالی کلید publishable را دارد.
- starter/site/assets/site-api.js درخواست شمارنده بازدید را می‌فرستد و کلید secret یا service-role در آن نیست.

## چرا محتوا از ساختار جداست؟

عامل هوش مصنوعی می‌تواند تجربه و پروژه‌ها را ویرایش کند بدون اینکه ساختار صفحه را از نو بنویسد. عنوان، تاریخ، نام و لینک تأییدشده وارد کنید. اگر مقداری مشخص نیست، آن را حذف کنید یا جای‌خالی روشن بگذارید.

## تغییر زبان

داده رزومه بخش‌های جداگانه فارسی و انگلیسی دارد. نمایشگر زبان و جهت سند را تغییر می‌دهد. انگلیسی چپ‌به‌راست و فارسی راست‌به‌چپ است. URL، ایمیل و نام فناوری را در متن ترکیبی خوانا نگه دارید.

## بک‌اند اختیاری شمارنده بازدید

صفحه رزومه به بک‌اند نیاز ندارد. شمارنده بازدید از یک جدول Supabase و یک تابع Edge استفاده می‌کند:

۱. مرورگر شناسه تصادفی خود را ایجاد یا از localStorage بازیابی می‌کند.
۲. رویداد بازدید و کلید عمومی publishable به تابع شمارنده فرستاده می‌شود.
۳. تابع مبدأ، کلید، ساختار درخواست و محدودیت نرخ را بررسی می‌کند.
۴. تابع شناسه مرورگر و IP را سمت سرور هش می‌کند.
۵. دیتابیس حداکثر یک بازدید برای هر شناسه مرورگر در هر روز UTC نگه می‌دارد.
۶. تابع تعداد تقریبی را برمی‌گرداند.

RLS فعال است و نوشتن مستقیم نقش ناشناس مسدود شده است. نوشتن دارای مجوز فقط سمت سرور انجام می‌شود. اگر شمارنده تنظیم نشده باشد، رزومه همچنان کار می‌کند.

## انتشار استاتیک

گردش‌کار GitHub Actions فقط starter/site را منتشر می‌کند. مستندات و سورس تابع سرور در مخزن می‌مانند و وارد خروجی سایت نمی‌شوند.

GitHub Pages کد سرور را اجرا نمی‌کند؛ تابع شمارنده در Supabase Edge Function اجرا می‌شود.

## تغییر امن پروژه

۱. فایل مرتبط و رفتار فعلی را بخوان.
۲. کوچک‌ترین تغییر درست را اعمال کن.
۳. متن فارسی و انگلیسی را هماهنگ نگه دار.
۴. node scripts/check.mjs را اجرا کن.
۵. موبایل، دسکتاپ، تغییر زبان، لینک‌ها و چاپ را آزمایش کن.
۶. اگر شمارنده تغییر کرده، پاسخ API را بعد از راه‌اندازی بررسی کن.
۷. فایل‌های جدید را از نظر اطلاعات شخصی و کلید محرمانه بررسی کن.

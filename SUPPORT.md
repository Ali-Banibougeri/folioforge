# Support

Before asking for help:

1. Read the relevant guide under docs/en or docs/fa.
2. Read AGENTS.md if you are asking an AI coding agent to change the project.
3. Run node scripts/check.mjs.
4. Include the exact error message and which step produced it.
5. Never include private résumé details, passwords, access tokens, or API secrets in a public issue.

When reporting a bug, say whether it happens in English, Persian, desktop, or mobile. For a game issue, name the game and the sequence of actions that reproduces it.

# Support

Before asking for help:

1. Read the relevant guide under docs/en or docs/fa.
2. Read AGENTS.md if asking an AI coding agent to change the project.
3. Run node scripts/check.mjs.
4. Include the exact error message and the step that produced it.
5. Never include private résumé details, passwords, access tokens, or API secrets in a public issue.

When reporting a bug, say whether it happens in English or Persian, on desktop or mobile, and whether the visitor counter is enabled. For counter issues, include the error code and the HTTP status, but redact private details and all credentials.
